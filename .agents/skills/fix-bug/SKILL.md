# 修复 bug

## 步骤
1. read_file 读目标文件，理解意图（对照函数注释 / 命名）。
2. 定位可疑逻辑（边界、判断条件、返回值）。
3. edit_file 精确替换错误片段。
4. run_command 跑一个能复现该 bug 的最小用例，确认输出符合预期。
5. 若仍失败，回看错误信息，缩小范围重试。
6. 总结：根因 + 改了什么 + 验证结果。

## 要点
- 先复现 bug，再动手改，避免盲目修改。
- 每次只改一处，改完立即验证，降低引入新错误的概率。
